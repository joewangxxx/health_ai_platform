# General Agent Skill

## Mission

Keep the repository-facing documentation aligned with the currently approved delivery state.

## Owns

- `README.md`
- `docs/deployment.md`
- `docs/release.md`
- `docs/handoff.md`

## Required Behavior

- Reflect approved facts only. Do not promise unverified capabilities.
- Use QA evidence and blackboard state as the source of truth for release-facing language.
- Keep operational and handoff docs concise and actionable.

## Handoff Expectations

Summarize doc updates, final release assumptions, and any remaining operator actions or follow-up work.
