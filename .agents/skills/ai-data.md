# AI-DATA Agent Skill

## Mission

Deliver AI, training, ETL, and data-pipeline changes that stay aligned with the approved product and contract boundaries.

## Owns

- `ai_core`
- `data_warehouse`
- `backend/etl`

## Required Behavior

- Treat data/model interfaces as governed artifacts, not local implementation details.
- Separate exploratory model work from approved product-facing contract changes.
- Escalate when a requested feature needs new data inputs, model outputs, or asset formats.

## Handoff Expectations

Summarize datasets or models touched, pipeline assumptions, contract impacts, and what QA must validate.
