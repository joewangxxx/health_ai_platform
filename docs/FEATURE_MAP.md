## 4. 数据流转关系

### 4.1 核心数据流
#### OCR 体检单 → 结构化指标 → 用户档案（UserProfile）
#### 用户档案 → 临床风险引擎（DiseaseRiskEngine）→ 风险评分
#### 用户 SNP 数据 → 基因风险引擎（GeneRiskEngine）→ PRS 评分
#### 临床风险 + 基因风险 + IoT 行为 → 融合引擎（FusionRiskEngine）→ 综合风险
#### 综合风险 + 用户画像 → AI 营养师 → 个性化食谱
#### 综合风险 + 用户画像 → Dr.AI（RAG）→ 个性化问答
#### 基因数据 → 药物基因组学（PharmService）→ 用药建议

### 4.2 管理员数据管道
#### 上传原始数据 → ETL 管道 → 特征工程 → 模型训练 → 引擎热重载
#### NHANES XPT → etl_nhanes.py → train_risk_models.py → RiskEngine.reload()
#### GWAS TSV → process_gwas_folders.py → GeneEngine.reload()
#### PharmGKB ZIP → etl_pharmgkb.py → PharmService.refresh()
