# 中文简历指标摘要

## STAR表达方向

**S/T**：围绕慢病风险评估与个性化健康干预场景，建设一个全栈 HealthAI 平台，解决健康数据分散、模型输出不可解释、AI健康咨询缺少安全治理的问题。

**A**：负责数据与模型资产、FastAPI Agent运行时、Vue3交互闭环、RAG/OCR集成边界、回归/E2E验证和多Agent协作治理。

**R**：可使用以下量化结果，但建议保留验证边界措辞。

## 可直接改写进简历的量化要点

- 评估35个持久化LightGBM慢病风险模型，覆盖13,137条NHANES衍生样本；中位ROC-AUC达到0.857，其中T2D AUC 0.911、高血压AUC 0.912、肥胖AUC 0.892、CKD AUC 0.767。
- 构建50份合成post-OCR体检报告抽取评测集；支持字段raw micro-F1达到1.000，全字段raw micro-F1为1.000，canonical payload micro-F1为1.000。
- 准备100题RAG检索评测集，覆盖841个Chroma知识片段；离线source Hit@5为0.840，MRR为0.785，已索引来源子集Hit@5为0.840。
- 设计100题、5类Agent安全治理评测集；确定性策略通过率、急症分流准确率、越权拒答准确率和工具白名单合规率均达到1.000。
- 建立100条答案质量rubric，覆盖要点覆盖、证据锚定、安全合规、行动建议和清晰度；离线候选答案通过率1.000，平均总分0.940。

## 推荐措辞

- 推荐写法：`仓库本地离线评估`、`合成post-OCR抽取评测`、`RAG离线检索基线`、`确定性Agent策略评测`。
- 暂不建议写：`临床级`、`医生级`、`外部临床验证`、`线上LLM真实效果`，除非后续补充对应实验。
