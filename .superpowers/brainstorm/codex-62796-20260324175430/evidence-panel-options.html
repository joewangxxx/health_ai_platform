Recommendation

Recommended: Option C

  • Fits the current Dr. AI page without a major layout rewrite
  • Lets us go beyond the current plain evidence tags
  • Keeps each answer tied to its own evidence context

Tradeoffs

  • Needs slightly more interaction logic than Option A
  • Still lighter than a full right-side evidence workspace
